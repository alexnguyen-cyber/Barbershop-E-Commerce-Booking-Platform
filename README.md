<h1>Barbershop E-Commerce & Booking Platform</h1>

<h2>Description</h2>

Developed a responsive, modern website for a local small business to streamline appointment scheduling and service browsing.

- Implemented a Stripe API checkout flow in sandbox mode to demonstrate end-to-end transaction handling.
- Utilized AI-assisted development tools (Cursor & Claude) to rapidly prototype and iterate on UI components.
- Managed the hosting and deployment of the live web application.

<h2>Utilities Used</h2>

- <b>Claude</b>
- <b>Cursor</b>
- <b>Stripe</b>
- <b>Vercel</b>
